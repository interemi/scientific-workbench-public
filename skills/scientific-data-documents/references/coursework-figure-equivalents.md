# Rebuilding a scientific figure for a presentation

Record the visual purpose and the source artifact before rebuilding a figure.
Identify the notebook cell or function, input FITS, table or RGB product,
coordinate frame and units, intensity scale, crop, overlays and intended slide.
Bundles should distinguish synthetic examples, reference material and
observations.

Work from a copy and retain the original. Reproduce the selected data product
and display parameters in a new output directory. Compare axes, units, colour
mapping, scale, crop, annotations and overlays against the reference. Record
any differences and the reason for them. A display-scaled image provides
visual evidence. Quantitative measurements need the calibrated source.

If the intended panel or source is unclear, record which identification remains
uncertain before preparing a candidate. If the user corrects the choice,
update the recorded source and display parameters before regenerating it.
