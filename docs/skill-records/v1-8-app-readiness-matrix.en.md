Status: Phase 2 matrix for the editable v1.8 workstream.

v1.7 classified whether a capability is useful outside its original domain.
v1.8 asks whether Scientific Workbench can invoke it predictably, parse its
result, find artifacts, preserve originals, and show useful errors or next steps.

Source of truth: `public_surface_registry.yaml` and
`references/real-world-capability-classification-v1-7.md`.

## App-readiness classes

| Class | Meaning |
| --- | --- |
| `app_ready` | Ready for app-like invocation with `summary_json`, clear artifacts, safe side effects, and clean failure behavior. |
| `app_ready_partial` | Useful from the app, but needs a wrapper, artifact typing, documentation, or a v1.8 envelope pass. |
| `cli_only` | Valid CLI route, but too narrow, stateful, or expert-dependent for normal app exposure at that time. |
| `blocked_optional` | Depends on an optional platform/backend condition; must block cleanly when unavailable. |
| `maintainer_only` | Internal release, smoke, registry, or validation work, outside normal user actions. |
| `not_applicable_to_app` | Too narrow for normal exposure except expert/direct CLI mode. |
