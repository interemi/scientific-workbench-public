# English editions of historical skill records

These publication derivatives preserve private historical documents while
removing machine-specific paths and translating prose. Dates, measurements,
warnings, and deferred work keep their original meaning. They do not establish
current installed-family promotion or replace the current installation guide.

Each edition identifies its private source commit and SHA-256. The
`distribution/public-documentation-map.json` mapping lists every original
path, including identical copies, and verifies both original and edition
hashes before export. The public snapshot keeps the established skill paths
and derives a manifest recording the transformations. Private originals remain
unchanged.
