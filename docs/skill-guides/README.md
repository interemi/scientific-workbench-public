## Export contract

`distribution/public-documentation-map.json` records each original and edition
path with both SHA-256 values and a review reason. The exporter applies these
replacements only to the new public snapshot. It preserves legacy paths and
symlinks so existing guide references still resolve, and derives the public
skill manifest with new sizes/hashes and explicit transformation provenance.

The private snapshot remains the unchanged preservation record. Do not copy
these editions over its historical guide paths. All ten unique retained skill
guides identified in the publication inventory now have English editions.
The strict public language, link, and portability checks must still pass on
the complete exported snapshot; this inventory alone is not that evidence.
